## Selected Projects

### [MediKiosk — Edge-First Clinical Intake](https://github.com/Aaryan7117/pts)
A clinical intake and patient-tracking application designed for multilingual healthcare workflows. The project brings together voice-based intake, prescription/report OCR, rule-based safety checks, and a clinician-facing triage queue. Its backend uses modular AI adapters so speech, OCR, and language-model components can be integrated independently.

**Technologies:** Python · FastAPI · SQLite · Pydantic · ASR/TTS/OCR integrations

### [Code Mate — Local AI Coding Assistant](https://github.com/Aaryan7117/code-mate-extension)
A VS Code extension powered by **Ollama and Llama 3.2**. It offers contextual chat, code explanations, code generation, diagnostics-assisted debugging, code review, and refactoring. The extension is designed to work with local models, without requiring hosted LLM API keys.

**Technologies:** TypeScript · VS Code Extension API · Ollama · Llama 3.2

### [AccurateFinRAG — Financial Document Question Answering](https://github.com/Aaryan7117/accuratefinrag)
A retrieval-augmented generation pipeline for financial reports, SEC filings, and structured PDFs. It combines structure-aware and semantic chunking with hybrid retrieval across vector, keyword, and table-oriented stores, followed by cross-encoder reranking and citation-grounded answer generation.

**Technologies:** Python · FastAPI · FAISS · BM25 · SQLite · Neo4j · OpenRouter

A related [local-model version](https://github.com/Aaryan7117/rag-chatbot-for-fin) explores quantized Llama inference for the same document-QA problem.
